# 2.2.1-preview 修复与验证记录

日期：2026-10-21。对应包名 `local.pin.preview`、versionName `2.2.1-preview`、versionCode 7，沿用 2.2 预览版的个人测试签名，以便覆盖更新；原版 `local.pin` 保持独立。

## 已确认的问题及改动

测试者反馈切换其他应用后，回到点位显示“运动自动暂停／调度中断”。2.2 的运动核心在两次更新间隔超过 5 秒时设置永久暂停，必须手动恢复；这与定位服务是否仍在运行不同，也不因最近任务锁定而改变。

现改为每次更新推进 `min(实际间隔, 5000 毫秒)`，超过部分丢弃，不再因为调度间隔自动暂停。反复每 8 秒才调度一次时，每次仍推进最多 5 秒，下一正常更新继续；手动暂停、结束时限、累计距离上限和完成后驻留仍保持。长中断会延长实际完成时间，不承诺冻结期间仍能持续提交位置。

Activity 退出只暂停地图和页面任务，定位运行在已有的 location 前台服务中。本次不增加后台定位权限、不增加自动启动；操作系统真的终止进程时仍不会自动恢复路线。

地图仍默认 OpenStreetMap，新增使用者自填 Key 的天地图官方 WMTS 入口，双层矢量底图和中文注记，独立缓存代际及动态可见来源署名。Key 私有保存，错误输出不包含完整 URL 或 Key；切换来源不重启定位服务。没有有效 Key 时不能据此声称天地图联网可用。
