# 路线运动预览版 2.2.1

此版本新增多点路线模拟，保留原来的静止选点模式。它模拟的是位置随时间的变化，不会让手机产生实际移动，也不会向其他应用伪造加速度计、陀螺仪或计步器数据。

## 安装预览包

交付的预览 APK 包名为 `local.pin.preview`，桌面名称为“点位·运动预览”，可与 `local.pin` 原版同时安装。无需卸载稳定版；系统同一时间只能选择一个模拟位置应用。

安装后，在开发者选项中将模拟位置信息应用选为“点位·运动预览”，打开手机定位，并按提示授予精确位置权限。需要切回原版时，停止预览版，再在开发者选项中选择原版“点位”。

本包沿用 2.2 预览版的个人测试签名，不使用原版 2.1 的签名；可覆盖更新旧运动预览版，但不是原版的覆盖升级包。源码及压缩包不附签名私钥。

## 地图选路线

切换到“路线模拟”，在地图上依次轻点位置，形成有序折线。可以撤销最后一个点或清空重选；最多 200 个点。开放路线至少需要 2 个点，闭环至少需要 3 个不同的点；相邻点不能重合，整条路线至少 1 米。

开启闭环后，会自动把末点连回首点，按顺序循环经过各条线段。运动沿所选折线或闭环边界行进，不是在多边形内部随机游走，也不会自动按道路规划或避开建筑。

运行中使用一份不可变路线，编辑需先停止。地图上的路线编号表示顶点，移动标记表示当前模拟位置。

## 速度、时间与距离

速度输入单位为 **km/h**，距离单位为 **米**，设置时间单位为 **分钟**。速度上下限必须为正且下限不大于上限，最高 360 km/h；两值相同即匀速。

- 开放路线按速度区间：沿整条路线走到终点，运行时间由路线长度和实际速度决定。
- 开放路线按总时长：根据路线长度除以指定时长，自动计算匀速。
- 闭环按累计距离和速度区间：累计达到所设米数后结束，可经过多圈或半圈。
- 闭环按运行时长和速度区间：达到指定运动时长后结束，实际累计距离随速度变化。
- 闭环按累计距离和总时长：根据目标距离除以指定时长，自动计算匀速。

区间速度在固定的模拟时间节点之间平滑变化；变化过程与 200 / 500 / 1000 毫秒的定位刷新频率分开。预计时间区间只是根据速度上下限计算的范围，不是精确完成时间承诺。

固定路线长度、固定时间和固定速度互相约束，不能任意指定三个互相冲突的数值。“距离 + 总时长”模式自动计算速度；需要速度浮动时，使用速度区间模式，并选择时间或距离之一作为结束条件。

## 暂停、完成与停止

“暂停运动”冻结位置、累计距离和运动时间，同时仍持续提交当前位置。“继续运动”从暂停点继续，暂停时间不计入目标时长。

2.2.1 修复了旧预览版因更新间隔超过 5 秒而永久自动暂停的问题。现在调度恢复后会自动继续运动，每次更新最多推进 5 秒对应的路程；超出部分不补跑，避免长时间中断后位置一次跳远。即使系统反复以较长间隔调度，每次恢复仍会前进，实际墙钟时间可能长于设置的运动时间。手动点击暂停后仍须手动继续。

本次修复针对进程仍在、调度延迟后恢复的情形。操作系统真正终止进程时，程序不会自动重启或恢复路线；前台服务和后台锁定也不能保证进程永远存活。

到达终点或设定上限后，运动完成并驻留最终位置，模拟定位仍在运行。点击“停止模拟”才清理测试位置源、释放运行资源，并交还系统重新定位。目标应用可能保留旧缓存。

## 传感器摇晃的范围

此普通 APK 没有跨应用传感器注入功能，不提供模拟摇晃次数或保证计步的开关。手机振动也不等同于其他应用读到模拟摇晃。

Android 的传感器数据注入属于专用测试接口，不是给第三方应用使用的公开定位权限；相关模式还依赖系统和传感器实现。参见 [Android SensorManager 源码说明](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/core/java/android/hardware/SensorManager.java)。

## 构建预览包

Android Studio / Gradle 的 debug 构建使用 `.preview` 后缀及预览名称。PowerShell 构建时显式传入预览参数：

```powershell
.\build-apk.ps1 `
  -JdkHome 'C:\path\to\jdk17' `
  -AndroidJar 'C:\path\to\android-36\android.jar' `
  -BuildTools 'C:\path\to\build-tools\36.0.0' `
  -ApplicationId 'local.pin.preview' `
  -ApplicationLabel '点位·运动预览'
```

未传入预览参数时，PowerShell 脚本仍以 `local.pin` 构建。自行生成的新签名通常不能覆盖原版安装。

2.2.1 交付 APK 沿用 2.2 预览版的测试证书和 `local.pin.preview` 包名，可覆盖更新旧预览版；它不能使用该证书覆盖原版 `local.pin`。地图来源设置见 [MAP_SOURCES.md](MAP_SOURCES.md)。
